Αρκετά είπα, πάμε να σε γνωρίσω και στα υπόλοιπα αρχεία:

## Περιεχόμενα

* `Python_tutorial.ipynb`: Ο βασικός παίκτης της ομάδας μας. Περιέχει μία καλή καταγραφή όσων κάναμε και μπορείς, ανοίγοντάς το (βλ. παρακάτω για το πώς) να αρχίσεις απευθείας την εξάσκηση.
* `Python_v1.1.pdf`: Σημειώσεις, σαν "θεωρία" + ασκησούλες. Προς το παρόν λίγες εντολές κλπ. λείπουν.
* `STARS.csv`: Κάποια στιγμή στο `Python_tutorial.ipynb` θα χρειαστεί να δουλέψουμε με δεδομένα (το περίφημο data analysis). Αυτό είναι απλώς το παράδειγμα που επιλέξαμε.
* `README.md`: Έι, εγώ είμαι αυτό!

## Πώς ξεκινάω να γράφω σε Python;

Η Python είναι η γλώσσα, το περιβάλλον όμως το διαλέγεις εσύ. Στα μαθήματα επιλέξαμε το Google Colab (βρίσκεται με μία αναζήτηση στο Google, δεν κατεβάζεις τίποτα). Μακροπρόθεσμα, η καλύτερη πρακτική είναι να εγκαταστήσεις την ίδια την Python στον υπολογιστή σου και να την εκτελείς από π.χ. VS Code ή Spyder ή Jupyter. Δε θα ασχοληθούμε με αυτά.

Τα "σκέτα" αρχεία Python έχουν την επέκταση `.py`. Τα `.ipynb` ("Jupyter notebook") διαφέρουν μόνο σε λεπτομέρειες όπως το ότι σου επιτρέπουν να γράφεις σε πολλά "κελιά" και να εκτελείς μόνο ό,τι χρειάζεσαι κάθε φορά. Πρακτικά λοιπόν είναι σχεδόν το ίδιο πράγμα.

Μπορείς να κατεβάσεις όλα εμάς (τα αρχεία) κάνοντας κλικ στο πράσινο |**<> Code**| και επιλέγοντας π.χ. Download ZIP.
